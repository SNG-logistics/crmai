# ระบบตรวจเงินเข้าจากแจ้งเตือนธนาคาร

ระบบนี้ใช้โทรศัพท์ Android ของร้านรับ Notification จากแอปธนาคารที่กำหนด แล้วส่ง
หลักฐานไปเทียบกับสลิปที่ลูกค้าส่งใน WhatsApp โดยอัตโนมัติ

> Notification ธนาคารเป็นหลักฐานประกอบที่แข็งแรงขึ้น แต่ไม่เทียบเท่า Bank API,
> statement หรือ webhook อย่างเป็นทางการ เครื่องที่ root หรือถูกควบคุมอาจปลอมข้อมูลได้

## สิ่งที่ระบบตรวจ

ระบบจะอนุมัติอัตโนมัติเฉพาะเมื่อครบทุกเงื่อนไขต่อไปนี้:

1. มาจากมือถือที่แอดมินลงทะเบียนและยังไม่ถูกระงับ
2. Package ID ของแอปธนาคารตรงกับ allow-list
3. SHA-256 ของลายเซ็นแอปธนาคารตรงกับค่าที่ pin จากการใช้งานครั้งแรก
4. เป็นรายการ `credit` หรือเงินเข้า ไม่ใช่เงินออก, OTP หรือโฆษณา
5. บริษัทและบัญชีรับเงินของสลิปถูกต้อง
6. เลขธุรกรรมเต็มตรงกัน
7. ยอดและสกุลเงินตรงกัน
8. รายการเงินเข้านั้นยังไม่เคยใช้ยืนยันสลิปอื่น

ถ้าตรงเพียงยอดเงินหรือเวลา ระบบจะไม่เดาและจะคงสถานะ `pending` ให้แอดมินตรวจ
ถ้าเลขธุรกรรมตรงแต่ยอดไม่ตรง ระบบจะแสดง `conflict` ถ้ารายการถูกใช้ไปแล้วจะเป็น
`duplicate`

## ตั้งค่าฝั่ง CRM

1. ตั้ง `API_CONFIG_ENCRYPTION_KEY` เป็นค่าสุ่มยาวและคงที่
2. ตั้ง `PUBLIC_API_URL` เป็น origin HTTPS ที่มือถือเข้าถึงได้ เช่น
   `https://crm.example.com` โดยไม่ใส่ `/api`
3. อัปเดตฐานข้อมูลด้วย `npx prisma db push` โปรเจกต์นี้มีฐานข้อมูลเดิมที่ถูก
   baseline นอก migration history จึงไม่ควรใช้ `prisma migrate deploy` ตรง ๆ
   โดยไม่ทำ baseline ให้ครบก่อน ไฟล์ migration
   `20260727090000_add_bank_notification_capture` เก็บไว้สำหรับตรวจสอบ SQL
   และระบบที่จัดการ baseline เดิมเรียบร้อยแล้ว
4. เปิดหน้า **ตั้งค่า → WhatsApp → บัญชีรับเงินสำหรับตรวจสลิป** แล้วกรอกธนาคาร,
   ชื่อบัญชี และเลขบัญชีของบริษัทให้ครบ
5. เปิดหน้า **ตั้งค่า → แจ้งเตือนเงินเข้า** เลือกบริษัท สร้างมือถือ และระบุ Package ID
   ของแอปธนาคารแบบตรงตัว
6. คัดลอก Server URL, Device ID, Device Secret และ Package ID ตอนที่ระบบแสดง
   เพราะ secret จะแสดงเพียงครั้งเดียว

## ตั้งค่าแอป Android

1. ติดตั้ง APK บนมือถือที่รับแจ้งเตือนบัญชีร้าน
2. กรอกข้อมูลลงทะเบียนจาก CRM แล้วกด **บันทึก**
3. กด **ทดสอบการเชื่อมต่อ**
4. กด **เปิดสิทธิ์เข้าถึงการแจ้งเตือน** แล้วเปิดให้ `CRM Bank Watch`
5. ทดลองรับเงินจำนวนน้อยหนึ่งครั้ง แล้วตรวจหน้า **แจ้งเตือนเงินเข้า**

แอปส่งเฉพาะรายการเงินเข้าที่อ่านยอดและสกุลเงินได้จาก Package ID ที่อนุญาต
ข้อมูลเงินออก, OTP, โฆษณา และ Notification จากแอปอื่นจะถูกทิ้งบนมือถือ

## เมื่อเครื่องหายหรือเปลี่ยนเครื่อง

- กด **ระงับ** ที่อุปกรณ์เดิมทันที
- ถ้ายังใช้เครื่องเดิมแต่สงสัยว่า secret รั่ว ให้กด **เปลี่ยนรหัส**
- การเปลี่ยนรหัสจะยกเลิก secret เดิมและ reset signer pin จากนั้นต้องใส่ข้อมูลใหม่ในแอป

## การดูแลข้อมูล

- Request ทุกครั้งลงลายเซ็น HMAC-SHA256 พร้อม timestamp และ nonce
- เซิร์ฟเวอร์กัน replay ด้วย nonce และกันใช้เงินเข้าซ้ำด้วยความสัมพันธ์แบบ one-to-one
- คิวบนมือถือและ secret ถูกเข้ารหัสด้วย Android Keystore/AES-GCM
- ข้อความ Notification ที่ต้องเก็บเพื่อตรวจสอบถูกเข้ารหัส และล้างอัตโนมัติหลัง 7 วัน
- ข้อมูล Notification ไม่ถูกส่งเข้าโมเดล AI

## ก่อนใช้งานเงินจริง

- ใช้ HTTPS ที่ใบรับรองถูกต้องเท่านั้น
- เซ็น release APK ด้วย keystore ขององค์กรและเก็บ keystore นอก repository
- ปิด battery optimization สำหรับแอป หากมือถือยี่ห้อนั้นหยุด WorkManager เบื้องหลัง
- ทดสอบรูปแบบ Notification ของธนาคารและเวอร์ชันแอปจริง เพราะแต่ละธนาคารใช้ข้อความ
  ไม่เหมือนกัน
- หากธนาคารมี API/webhook อย่างเป็นทางการ ให้ใช้ข้อมูลนั้นเป็นหลักฐานระดับสูงกว่า
  Notification
